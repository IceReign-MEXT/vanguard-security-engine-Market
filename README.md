# 🛡️ Vanguard V100 - Omni-Chain Security Forensics

**The Ultimate Web3 & Web2 Threat Detection Engine.**

Vanguard is an automated cyber-security firm in a box. It scans Ethereum, Solana, Bitcoin, and Web2 domains for critical vulnerabilities, honeypots, and exploits.

## ⚡ Features
*   **Multi-Chain Intelligence:** Auto-detects target type (ETH/SOL/BTC/HTTP).
*   **Dynamic Quote Generation:** Calculates the cost to fix vulnerabilities based on threat severity.
*   **Automated PDF Reports:** Generates professional, white-labeled audit certificates.
*   **Channel Broadcasting:** Pushes live threat detections to Telegram communities.
*   **Full-Stack Dashboard:** Real-time web interface for monitoring global scans.

## 🛠 Deployment
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Configure `.env` with Telegram and Database credentials.
4. Deploy to Render using Python 3.11 Runtime.
