# 🛡️ VANGUARD SECURITY ENGINE

**Automated Cyber-Security & Blockchain Forensics Terminal.**

Vanguard is an institutional-grade auditing tool used to detect vulnerabilities in Websites and Smart Contracts. It generates professional PDF reports for clients, identifying security risks, speed issues, and SEO failures.

## ⚡ Capabilities
*   **Website Auditor:** Scans SSL, Headers, Speed, and SEO.
*   **Wallet Forensics:** Analyzes ETH/SOL wallets for suspicious activity.
*   **PDF Generator:** Creates instant white-label security reports.
*   **Dashboard Sync:** Logs all audits to the IceGods Central Command.

## 🛠 Deployment
1.  **Clone Repo**
2.  **Install Requirements:** `pip install -r requirements.txt`
3.  **Deploy to Render:** Python 3 Runtime
4.  **Start Command:** `python main.py`
