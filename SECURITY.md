# Security Policy

## Supported Versions
We only provide security updates for the latest version of Vanguard.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes             |
| < 1.0   | ❌ No              |

## Reporting a Vulnerability
If you find a security issue within this tool, **DO NOT** create a public GitHub issue. 

Please report vulnerabilities privately by:
1. Sending a DM to our Telegram: `https://t.me/your_telegram_username`
2. Or via Email: `your-email@example.com`

We will respond within 24 hours to coordinate a fix.
